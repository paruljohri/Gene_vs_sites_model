Here are the descriptions of the scripts here. All of these relate to calculation of population genetic statistics from the simulated data.

-get_af_from_ms_general_reps.py
This python script reads a .ms file (simulation output) and calculates average frequency of the selected allele at each site for each simulation replicate.

-statistics_LD_general_reps.py
This python script reads a .ms file (simulation output) and calculates LD statistics between pairs of selected allele for each simulation replicate.

-run_calculate_LD_af_stats.sh
Command lines used to obtain mean allele frequencies and LD statistics across simulation replicates when there is no epistasis.

-run_calculate_LD_af_stats_epistasis.sh
Command lines used to obtain mean allele frequencies and LD statistics across simulation replicates when there is epistasis.

-run_calculate_LD_af_stats_humans.sh
Command lines used to obtain mean allele frequencies and LD statistics across simulation replicates in human-like simulations when there is no epistasis.

-summarize_load_stats.py
Obtain load statistics from the ouput of each simulation replicate when there is no epistasis.

-summarize_load_stats_epistasis.py
Obtain load statistics from the ouput of each simulation replicate when there is epistasis.

-summarize_load_stats_humans.py
Obtain load statistics from the ouput of each simulation replicate for human-like simulations with no epistasis.
